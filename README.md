# NPTEL Wildlife Ecology Exam Series (Top 10 Tests - 500 MCQs)

Interactive examination preparation platform for **NPTEL Wildlife Ecology** taught by **Dr. Ankur Awadhiya** (Indian Forest Service, IIT Kanpur).

## Features
- **10 Full-Length Tests** (50 Questions each = 500 Questions total)
- **Assignment Coverage**:
  - Test 1: Assignment Weeks 1 & 2 (20 Qs) + 30 Foundations Qs
  - Test 2: Assignment Weeks 3 & 4 (20 Qs) + 30 Energetics & Interactions Qs
  - Test 3: Assignment Week 5 (10 Qs) + 40 Population Ecology Qs
  - Tests 4-10: Community Ecology, Biogeography, Threatened Species, Human Dimensions, Pollution & Climate Change, Applied Management, and Grand Final Certification Mock
- **Instant On-Tap Reveal**: Green/Red highlights, correct answer identification, and detailed explanations immediately on selection.
- **Diagnostic Scorecard**: Overall score, accuracy, and in-depth breakdown of wrong answers vs correct answers.
- **Device Friendly**: Responsive UI optimized for mobile phones, tablets, and PCs.
